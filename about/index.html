Hi, I'm Mike. I live in Provinceton, which is either in Clayton or Cloverdale depending on who you ask, and the Surrey Langley SkyTrain is going up a short walk from my house. Most days I'm out along the line with Piper and Toby, my two trusty assistants, or on my bike, watching the Clayton Clipper inch its way west one span at a time.

This started as a drawing. In mid-October I sketched the stretch of guideway past the South Fraser Maintenance and Storage Facility, mostly to share on a forum. Then I kept fixing it, and it kept growing. Now it's a map of the Clipper's whole route, plus Trackside, where I post what I see along the way.

Why only the Clipper? There are four gantries building this line. The Fleetwood Flyer is done, and as of Nov 1, 2026, the Surrey Sprinter only has about six spans to go. The Langley Launcher is just too far to walk. So I'm sticking with the Clayton Clipper. But the whole thing is open source, so if someone wants to take on the Langley Launcher, go for it.

It's just me. This is a hobby project. I'm not connected to TransLink, TI Corp, the Province, or anyone building the line, and nobody official has checked any of this. Spans and supports are placed as carefully as I can manage, but they're approximate. Anything that hasn't been built yet is my best guess, so please don't plan anything important around it.

The Clayton Clipper logo isn't mine. It belongs to the Surrey Langley SkyTrain project. I've asked permission to use it, and I'll take it down if they'd rather I didn't.

Where things come from. The photos are mine, so blame me for those. The sources for the map are listed in the data README on GitHub.

Comments. Comments on Trackside are GitHub Discussions, so you'll need a GitHub account to join in, and your username will show next to what you write. The site itself doesn't track you or set any cookies.

Yes, I make websites for a living, and have since 1997. No, I'm not trying to make money off this one. I've spent most of my career on the back end, where the design is someone else's job. With AI, I can finally build something that looks nice all on my own, and that's what makes this so much fun. Add more than 20 years of Garmin GPS fitness trackers, and I'm a huge map nerd too. I nearly became the lead developer on DriveBC once, but I was tied up on another project.

How it's made. The first version was a single, very large HTML file that the Claude app built as a viewer for my drawing. To split it into manageable pieces, I moved it to Svelte, which looked simpler than React, and I got to learn a new framework along the way. It's hosted on GitHub Pages. I update it from the Claude app while I'm out on the bike or walking the dogs, and do the bigger changes with Claude Code back at my computer. All the code is on GitHub.

Why Svelte? The map is one big SVG drawing, and the code needs to reach inside it to colour individual spans, place the gantry, and switch layers on and off. Showing it with an ordinary <img> tag would have turned it into a black box. Svelte made it easy to split the code into components while keeping the SVG embedded directly in the page, and its reactivity means flipping a layer switch updates the map automatically. It also builds Trackside into plain HTML pages, so search engines can read them, and it compiles down to small, plain JavaScript. For a static site on GitHub Pages, it turned out to be a good balance of organization, flexibility and simplicity.
